About me

Smart homes that
run locally.

I'm a developer focused on home automation. My own house is the test bed: a Home Assistant hub with Alexa, Tailscale for remote access, Pi-hole for DNS, and a Docker stack on an Ubuntu server I run myself.

I keep things local so they keep working when the internet doesn't. Next up are ESP32 devices for watering and blinds, reporting into Home Assistant.

I have a CS degree and an applied AI background, so I'm also working toward local vision and voice models that trigger automations.
